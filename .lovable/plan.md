# Light Optimum Hub

## Goal
Rework the current dark horizontal presentation into a bright, premium Optimum module explorer inspired by the supplied reference.

## Experience
- Keep five persistent modules in a left navigation rail.
- Open Official Links by default.
- Replace the right side in place when a module is selected.
- Support previous/next controls and arrow-key navigation.
- Preserve the existing Optimum links, team, reading, playground, and resource content.

## Visual direction
- White and pale-blue liquid glass instead of a dark theme.
- Fustat for branded headlines and Inter for interface text.
- Subtle blue grid, glow, moving nodes, translucent surfaces, and restrained depth.
- Use an Optimum infinity wordmark rather than the unrelated Taskly branding.
- Collapse the left rail into a horizontal module selector on smaller screens.

## Technical details
- Reuse the existing local image assets and external destination links.
- Use Motion transitions between module states.
- Keep route metadata unique and app-specific.
